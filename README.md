# Registration Form Java Web Application

A simple registration form with user validation, password validation, and database connection. Users can sign up with a username, email, and password. The password is validated for complexity, and the data is stored in a MySQL database.

## Features
- User registration with fields for:
  - Username
  - Email
  - Password
  - Confirm Password
- Validations for:
  - Username (alphanumeric only)
  - Password (must contain at least one special character)
  - Password match confirmation
- Data is stored in a MySQL database.

## Requirements
- Java 8 or higher
- MySQL Database
- NetBeans IDE
- JDBC MySQL Connector
